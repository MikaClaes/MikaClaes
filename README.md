## 🔭 What I'm currently working on

### ⚡ VGC Sleeper-Pick Predictor
A machine learning tool that identifies underrated "sleeper picks" for competitive Pokémon (VGC). Instead of relying on popularity or battle history, it evaluates under-used Pokémon based purely on intrinsic attributes (typing, stats, moves, speed tiers) to predict matchup outcomes against top-meta threats.

- **Data Pipeline:** Pulling Showdown replays, Smogon chaos JSONs, and Pokédex feature vectors.
- **ML Core:** Training a classifier to predict pair/team matchup performance based on feature differentials.
- **Goal:** Launching a minimal API/Streamlit app that outputs a ranked shortlist of high-potential off-meta picks with explainable reasoning.
